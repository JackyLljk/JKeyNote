### 1.1 LLM 

**大语言模型（Large Language Model，LLM）**

基于 LLM 的自主 Agent 系统中，LLM 充当 Agent 的大脑，并由几个关键组件辅助

**规划 Planing**

- 子目标和分解
- 反思与改进



**记忆 Memory**

- 短期记忆：所有的情境学习 in-context learning（提示工程 Prompt Engineering 等）都是利用短期记忆进行学习
- 长期记忆：利用外部向量存储和快速检索，为 Agent 提供较长时间内保留和回忆信息的能力



**工具使用 Tool use**

- Agent 调用外部 API 获取模型权重中缺失的额外信息（当前信息、代码执行能力、对专有信息源的访问权限等）
