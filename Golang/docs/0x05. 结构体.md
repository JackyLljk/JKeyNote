## 结构体

### 自定义类型

Go 可以使用 `type` 关键字定义自定义类型

```go
type MyType int		// 将 MyType 定义为 int 类型
```

Go1.9 后添加类型别名功能，可以给类型定义别名（同类型的别称）

```go
type NewInt int		// 类型定义
type MyInt = int	// 类型别名

var a NewInt	// type of a:main.NewInt
var b MyInt		// type of b:int
```

- 类型定义显示 main 包下定义的 `NewInt` 类型，而类型别名只在代码存在，编译完成时显示为原类型



**结构体：**Go 提供的自定义数据类型，可以封装多个基本数据类型，本质是一种聚合型的数据类型

```go
type typeName struct {
    字段名	字段类型
    字段名	字段类型
    ...
}
```

- 类型名在包内不能重复，字段名在结构体内必须唯一

<br>

### 结构体实例化

结构体本身是一种类型，可以像声明（+定义）内置类型一样使用 `var` 关键字，通过 `.` 访问结构体的字段

- 当结构体实例化时，才会真正地分配内存

```go
type resonator struct {
    name string
    attribute string
    weapon string
}

func main() {
    ...
}
```

#### 实例化结构体

```go
var aemeath resonator	
    
// 手动赋值
aemeath.name = "爱弥斯"
aemeath.attribute = "热熔"
aemeath.weapon = "迅刀"
```

#### 指针类型结构体

 Go 支持对结构体指针直接使用 `.` 来访问成员

```go
var shorekeeper = new(resonator)

// 对结构体指针直接使用 . 来访问成员
fmt.Printf("%T", shorekeeper)	// *main.resonator

shorekeeper.name = "守岸人"
shorekeeper.attribute = "衍射"
shorekeeper.weapon = "音感仪"
```

使用 `&` 对结构体进行取址操作，相当于进行了一次 `new` 实例化操作

```go
cartethyia := &resonator{}

fmt.Printf("%T", cartethyia)			// *main.resonator
fmt.Printf("Carte = %#V", cartethyia)	// Carte = &main.person{name:"", attribute:"", weapon:""}

cartethyia.name = "卡提希娅"
cartethyia.attribute = "气动"
cartethyia.weapon = "迅刀"
```

- `cartethyia.name = "卡提希娅"` 底层相当于 `(*cartethyia).name = "卡提希娅"`，属于 Go 实现的语法糖

#### 匿名结构体

在定义一些临时数据结构场景下可以使用匿名结构体

```go
var npc struct{Name string; Age int}
npc.Name = "曼波"
npc.Age = "2333"
```

### 结构体初始化

没有初始化的结构体，其成员变量都是对应类型的零值

```go
// 使用键值对初始化
iuno := resonator{		// 或者 iuno := &resonator{...}，得到初始化后的结构体指针
    name: "尤诺",
    attribute: "气动",	
    weapon: "臂铠",
}

// 使用值的列表初始化
camellya := &resonator{
    "椿",
    "湮灭",
    "迅刀",
}
```

值列表初始化需要满足条件：

1. 必须初始化所有字段
2. 值列表和字段声明顺序一致
3. 不可和键值对初始化混用
